# ⚡️ Pyryatin Light Bot (Група 2.1)

Telegram-бот для моніторингу графіків відключень світла в **Полтавська області**. Бот автоматично збирає дані, адаптовані під графіки «Полтаваобленерго», та надсилає персональні сповіщення користувачам.

## 🏗 Архітектура системи

Проєкт побудований на моделі **Producer-Consumer** (Виробник-Споживач), що забезпечує стабільність роботи навіть при суворому захисті джерела даних.



* **Parser (Producer):** Фоновий скрипт, який обходить захист Cloudflare за допомогою **Bright Data Web Unlocker** та оновлює локальну базу даних (`schedule_data.json`).
* **Bot (Consumer):** Асинхронний Telegram-бот на базі `aiogram 3.x`. Він миттєво віддає дані користувачу з локального файлу, не навантажуючи сайт запитами.
* **Monitor Task:** Внутрішній процес бота, який щохвилини звіряє поточний час із графіком і робить розсилку підписникам за 5 хвилин до події.

## ✨ Основні можливості

* **Миттєвий запит:** Отримання актуального графіка для групи 2.1 однією кнопкою.
* **Розумні сповіщення (за 5 хвилин):**
    * 🔴 **Перед вимкненням:** Бот попереджає про початок темряви та вказує тривалість відключення.
    * 🟢 **Перед ввімкненням:** Бот повідомляє про появу світла та розраховує, до котрої години (орієнтовно) воно буде.
* **Адаптивний UI:** Зручні Inline-кнопки для керування підпискою та оновлення даних.
* **Локальний час:** Робота виключно за київським часом (`Europe/Kyiv`).

## 🛠 Технології

* **Python 3.10+**
* **aiogram 3.x** (Telegram Bot API)
* **BeautifulSoup4** (Парсинг HTML)
* **Bright Data Web Unlocker** (Proxy для обходу 403 Forbidden)
* **JSON** (Як легка база даних)
